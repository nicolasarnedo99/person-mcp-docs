## v0.1.0

The first documented release.

- Five tools: `search-people`, `get-person`, `list-tracked`, `import-person`
  and `log-interaction`
- Local JSON store in `people.json`, gitignored by default
- Streamable HTTP endpoint at `/mcp`, with the mcp-use Inspector at
  `/mcp/inspector`
